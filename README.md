## Install

Every component is one file, and every name in this README installs the same way. The CLI reads [`registry.json`](registry.json) from this repo, copies the file to `components/viberdy/<name>.tsx` and installs the npm packages it imports.

```bash
npx shadcn@latest add viberdy-dev/ui/card-carousel-3d viberdy-dev/ui/flip-card   # several at once
npx shadcn@latest list viberdy-dev/ui                                       # everything in this registry
npx shadcn@latest view viberdy-dev/ui/liquid-glass-button                    # inspect before installing
```

No shadcn set up? Copy the file from [`components/`](components) and install what it imports.

- **The export name can differ from the file name** (`card-carousel-3d` exports `CardCarousel3D`), so import what the file exports. Props are typed on the function.
- **Stack:** React 18 or 19 and Tailwind CSS v4, built for the Next.js App Router. Each file is a client component (`"use client"`). 112 need nothing beyond React; the rest add `framer-motion` (48) or `lucide-react` (11). No network calls, no telemetry.
- **Typefaces:** components designed around a particular face read it from a CSS variable (such as `--font-display`) and fall back to your sans font. Most name the face and how to load it in their header comment.
