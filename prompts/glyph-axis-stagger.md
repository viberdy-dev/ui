# Glyph Axis Stagger: AI prompt

Paste this into Cursor, Claude Code, v0, Lovable or Bolt to generate **Glyph Axis Stagger** from scratch, or edit it first to restyle it. The finished code is [components/glyph-axis-stagger.tsx](../components/glyph-axis-stagger.tsx); the live demo is on [viberdy.dev](https://viberdy.dev/library/glyph-axis-stagger?ref=github).

````text
Build a React + Tailwind primitive, `GlyphAxisStagger({ text, as, from, to, trigger, play, once, stagger, order, flash, palette, tone, className, style })`.

The engine (a hook over a host element): every letter is a span inside a line; each frame it asks the part for each letter's goal (a setting, a load for the accent, an opacity), springs every axis toward it, writes font-variation-settings, colour and opacity for every letter, then reads every line's width and letter position once (all writes before all reads, so one layout a frame). A flush line is kept exactly as wide as its box by one width offset added to all its letters: sized first by measuring the line at its rest setting at 100px with no offset and with +20 wdth (which gives its width and its px per wdth unit, so its size and offset), then corrected a step each frame (85% of the error); only when the offset is pinned at the axis limits does the size move. New text eases its size over ~200ms while the offset keeps it flush. A face without a width axis measures the same twice, so those lines fit by size alone. It sleeps once everything has settled, wakes on pointer, scroll, resize or new fonts, and runs only near the screen.

Here: from and to are named settings (hairline 100/72/CTRS 85, quiet 160/72, set 420/100, loud 860/150/70, packed 900/56) or axes. Keep the last change ({ on, at }); a letter whose turn has come (now >= at + order(i) x stagger) takes the new side, one still waiting keeps the old, so a reversal runs in the same order. order(i) is i, n-1-i, |i - mid| or mid - |i - mid|. trigger "view" plays at 60% visibility (once, or each time), "hover" on pointer enter and focus, "manual" follows play. flash lights each arriving letter in the accent, fading over 420ms. Letters start at from (and render that way before the engine runs).

Kinetic Type grammar: paper #f0ede2 with ink #131315 (ink at 68/46% for secondary text, hairlines at 14% and 30%), and an inverted ink stage (#131315 ground, #f0ede2 ink) for one loud section. One accent that letters take only under load, ink to accent by how hard they are pressed: cobalt #2b3bff on paper (#8f98ff on ink), or vermilion #d9360b (#ff6a3d), or mono. Science Gothic through var(--font-science, "Science Gothic", ...) for display, with four axes that are the interface: wght 100-900, wdth 50-200, slnt -10-0 and CTRS (contrast) 0-85; Geist for reading and Geist Mono uppercase for readouts and labels. Three named settings: quiet (wght 160, wdth 72), set (420, 100) and loud (860, 150, CTRS 70). Display lines are set flush: exactly as wide as their box, the width axis solved live, and lines that share a size stand at one cap height. Radius 0 on type, 12px on cards and controls. Motion is springs (stiffness 220, damping 24, a slight overshoot), rebuilds staggered 24ms a letter, pointer pressure as a gaussian over about one letter height, sweeps leaning letters by up to 10 degrees of slant. Letters are real, selectable text named once for assistive tech (aria-label on a heading or button, else a visually hidden copy) with the split letters aria-hidden. Respect prefers-reduced-motion (settings still apply, without travel; no pressure, no entrances). No dependencies beyond React.
````
