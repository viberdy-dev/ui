# Spec Numeral Tile: AI prompt

Paste this into Cursor, Claude Code, v0, Lovable or Bolt to generate **Spec Numeral Tile** from scratch, or edit it first to restyle it. The finished code is [components/spec-numeral-tile.tsx](../components/spec-numeral-tile.tsx); the live demo is on [viberdy.dev](https://viberdy.dev/library/spec-numeral-tile?ref=github).

````text
Create a React + Tailwind client component file exporting SpecNumeral and SpecNumeralTile: a big numeral in a bento spec-sheet voice whose digits roll into place like an odometer the first time it scrolls into view.

SpecNumeral props: value (number), decimals (default 0), group (thousands separators, default true), prefix, unit, duration (ms per column, default 650, so a six-digit figure settles inside 900ms), replayKey (changing it rolls the number again), className, style. Format with toLocaleString("en-US") (a non-finite value becomes 0). Render a visually hidden span with the full text (prefix, number, unit) for assistive tech, and an aria-hidden visual: the prefix, then one element per character. Separators stay static; each digit is an inline-block, 1em tall, overflow hidden, holding an invisible "0" for width and an absolutely positioned column of the digits 0–9 (each 1em tall, line-height 1). Rolling: translateY(−digit em) with a transition of `duration` ms on cubic-bezier(0.16, 1, 0.3, 1), delayed 45ms per position counted from the right, so the right-most digit lands first and the most significant digit lands last. Key each column by its place value from the right so it keeps its identity when the digit count changes. Add motion-reduce:!transition-none to the column so reduced motion never rolls. Before it rolls, every column sits at 0 with no transition. The unit follows in a lighter weight at 0.42em and 60% opacity. The numeral is set in the page grotesque (not mono: a mono headline number reads as a terminal), bold, with tabular numbers, letter-spacing −0.045em and line-height 1. Mono (var(--font-mono, var(--font-geist-mono, ui-monospace, SFMono-Regular, Menlo, Consolas, monospace))) is for the metadata label only.

Trigger: an IntersectionObserver (threshold 0.4, read the last entry) that, once the numeral is in view, disconnects and flips a `shown` state 40ms later so the columns roll from zero. Under prefers-reduced-motion, show it at once. Reset on a new replayKey by adjusting state during render (compare against the last key), which re-arms the observer.

SpecNumeralTile props: label (a mono metadata label), value, decimals, prefix, unit, caption?, delta? (a short change note), accent ("#rrggbb", regex-validated, default #ff5a1f), size ("md" for a 1x1 tile, "lg" for the 2x2 hero tile), replayKey, className. The tile is the bento kit's: a Tailwind `@container`, rounded 20px, background #0f1012, a 1px hairline as inset 0 0 0 1px rgba(255,255,255,0.08), no drop shadow, padding 16px (24px for lg), a flex column spaced between. Top row: the label (11px, uppercase, +0.12em, mono, white 50%) and the delta chip (mono 11px in the accent, the accent at 12% behind it and a 25% accent hairline). Bottom: the numeral (bold) sized to the tile with container units (lg clamp(48px, 24cqw, 112px); md clamp(28px, 22cqw, 44px)) so any value fits, and an optional caption (13px, white 60%).

Output one self-contained "use client" TSX file with no dependencies beyond React. Build strings with + rather than template literals.
````
