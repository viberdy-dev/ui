````text
Create a React + Tailwind client component, HairlineTileButton: a dark bento-style button that behaves like a live bento grid. At rest it is one flat tile (a tonal face, a 1px hairline, no shadow). On hover or keyboard focus its face re-tiles into compartments along hairline seams, nothing lifts, a light under the pointer runs along the seams, a press compresses the compartments toward the pressed point, and its keycaps are a real keyboard shortcut.

Props: children, href (renders a sanitised link: strip tabs and newlines, reject backslashes, allow http(s), mailto, tel and relative paths starting / # ? but not //), onClick, type ("button" | "submit"), variant ("tile" | "accent"), size ("md": 44px min height, 14px text, 12px label padding, 36px arrow tile | "lg": 56px, 15px, 16px, 48px), meta (mono metadata above the label), kbd (keycap labels: with shortcut they only relabel its caps when the count matches, alone they are a static hint), shortcut (a live combination: "shift+d", "mod+k" where mod is Cmd on Mac and Ctrl elsewhere, "alt+enter", "/"), icon (leading, 18px), arrow (ReactNode: true for "→", false for none, or a custom trailing glyph; default true), accent ("#rrggbb", regex-validated, default #ff5a1f), disabled, className.

Anatomy (keep the layout fixed so the button never changes width): the root (a or button, class "htb") is inline-flex, overflow hidden, radius 14, background var(--grout). Inside, a "plate" (relative flex, the part that compresses) holds: an under-light layer, then absolutely positioned tile surfaces, then the in-flow row (relative, flex, 4px padding, 4px gaps) with three cells: the label cell (flex 1, icon + a column of meta and a truncated 500-weight label), the keys cell (the keycaps, 6px side padding) and the arrow cell (a square as wide as the size's arrow tile, glyph centred). After the plate: an outer hairline layer (inset 1px ring) and an outer ring-light layer.

Surfaces: the label surface at rest covers the whole face (inset 0, radius 14, the face colour, no hairline). Open, it insets to top/left/bottom 4px and right = the measured tail (row width minus the label cell's right edge; write it to --htb-tail from a ResizeObserver on the row, label and keys cells, and the keys cell width to --htb-kw), radius 10, the raised tile colour, an inset 1px hairline. The keys surface sits at right = 4px + arrow width + 4px, top/bottom 4px, width 0 at rest and --htb-kw open, a recessed well colour. The arrow surface sits at right 4px, width 0 at rest and the arrow width open. So the label tile yields width and the other tiles grow in from the trailing edge. Stagger opening 0 / 60 / 120ms (label, keys, arrow) on the spring cubic-bezier(0.34,1.25,0.64,1) over 320ms; closing reverses it (arrow 0, keys 40, label 80ms) on cubic-bezier(0.16,1,0.3,1) over 280ms. The root's background steps to a darker grout while open, so the seams read as channels between tiles. The arrow glyph goes from 60% opacity and -3px to full and 0, with the arrow tile's delay.

The open state is a static stylesheet rendered in a <style> tag beside the element: .htb:focus-visible, .htb[data-press] and, inside @media (hover:hover), .htb:hover. Build the CSS with a helper that writes one rule for all three. Colours only arrive through custom properties set inline from validated hex values. Tile variant: face and rest grout #0f1012, open grout #08090a, tiles #16171a, keys well #131417, compartment hairline white 0.1, outer hairline white 0.08 (0.16 open). Accent variant: face and tiles are the accent, the open grout is the accent mixed 34% toward black, the well 14% toward black, hairlines white 0.3 / 0.22 / 0.4, and the text is #0b0b0c or white by the accent's relative luminance (above 0.18 means dark text). Focus ring: .htb:focus-visible { outline: 2px solid (the accent, or white on the accent variant); outline-offset: 2px; border-radius: 14px }, so an unlayered global :focus-visible rule in the host cannot replace it.

Light: on pointermove, coalesced to one write per animation frame, map the pointer into the button's layout pixels (rect-to-offsetWidth ratio, so it works in transform-scaled containers) and write --htb-x/--htb-y on the root and --lx/--ly on every surface (pointer minus the surface's offsetLeft/offsetTop). Three layers use it, all fading in over 200ms while open: the outer ring (a 1px ring made with padding 1px plus the mask-composite exclude trick, radial 90px of white 0.55, 0.9 on accent); each surface's own ring (an ::after, radial 80px); and the under-light (radial 64px, white 0.24, 0.45 on accent) that shows only through the seams. Cancel a pending frame on pointerleave. On keyboard focus (matches(":focus-visible")) remove the position variables so no stale light shows.

Press: on pointerdown (primary button, or any touch or pen), write the point as --htb-px/--htb-py and set data-press; remove it on pointerup, pointercancel, pointerleave and blur. Enter (and Space on a button) sets it with the origin at the centre. While pressed the plate scales to 0.965 about that point in 110ms (the compartments compress toward the finger; nothing lifts) and every surface gets a black veil (::before at opacity 0.32, or 0.14 on accent) as a tonal step; release springs back over 320ms. A touch press also opens the tiles.

Real keycaps: parse the shortcut into modifiers (mod, ctrl, meta, alt, shift, with common aliases) and a key. Caps show ⌘/Ctrl for mod, ⌃/Ctrl, ⌘/Meta, ⌥/Alt and ⇧, with Mac read through useSyncExternalStore (server snapshot false) so hydration never mismatches; keys map Enter to ↵, Escape to Esc, arrows to arrow glyphs, letters to capitals. Set aria-keyshortcuts ("Shift+D", "Meta+K"). In an effect, add window keydown/keyup/blur listeners and an IntersectionObserver: act only while the button is on screen and neither the event target nor document.activeElement is a text field (text inputs, textarea, select, contenteditable). Match the key by e.key or, for letters and digits, e.code (layout-proof), and require the modifiers exactly (Shift is not held against punctuation such as "?"). On a match, preventDefault, and unless it is a repeat: depress the key cap (data-down), set data-press with the origin at the keys cell's centre, and call element.click(). On keyup of the key, release after at least 140ms so a quick tap is still seen. Held modifiers depress their own caps on every key event; blur clears everything. Caps: 24px tall, radius 6, mono 11px, inset 0 -1px 0 black 0.35 plus a 1px ring; down they move 1px, lose the bottom edge and brighten, 90ms linear.

Reduced motion: every transition and delay goes to 0ms and the plate never scales, so the re-tile and the press are instant. No drop shadows anywhere. Mono stack: var(--font-mono, var(--font-geist-mono, ui-monospace, SFMono-Regular, Menlo, Consolas, monospace)).

Output one self-contained "use client" TSX file with no dependencies beyond React. Build strings with + rather than template literals.
````
