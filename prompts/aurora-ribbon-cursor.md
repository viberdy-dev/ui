Build a React + Tailwind wrapper, `AuroraRibbonCursor({ children, palette, life, width, rays, layer, attract, className, style })`.

A relative host with a 2D canvas absolutely inside it (under or over the children, pointer-events none), sized to the host at devicePixelRatio up to 2. On pointermove convert to layout units (correcting for scaled ancestors), push { x, y, t, v } (v = px/s) and fill gaps longer than 6px with interpolated points (at most 14); keep at most 180. Each frame drop points older than life, clear, set globalCompositeOperation lighter, and for each segment: colour by its index along the ribbon through fringe, core2, core, blend, high; alpha 0.55 x age squared; a halo stroke (width x 4.5, alpha x 0.2) and a core stroke; and, with rays, a 2px vertical gradient rising (14 + min(46, v x 0.03)) x (0.35 + 0.65 age) px. A soft radial at the head. Run the loop only while there are points (or, with attract, while visible). Attract: after 2.5s without real movement, lay a ghost stroke across the middle over 1.8s every 10.8s.

Aurora grammar: a near-black night #050608 (panels #0a0d12, raised #0f141a; ink #ecf4f8 at 94/64/42%; hairlines at 8% and 16%). The light is real aurora, coloured by altitude: a core in mint #7cf5c4 drifting toward sky #38bdf8 on one shared 60s clock, a violet #a78bfa blend above it, a rose #f472b6 crown seen only in a strong display, and an indigo #5b6cc4 fringe under the lower border (palettes: boreal, verdant #6ee7a0, violet). Bricolage Grotesque through var(--font-bricolage, "Bricolage Grotesque", ...) at 600-650 for lit display type only, Geist for UI, Geist Mono uppercase captions. Motion: the 60s aurora clock, ambient drifts of 30s and longer, discrete hover or focus changes under 450ms, pointer chases that settle over 600-900ms (1 - e^(-4dt)); WebGL runs at 30fps and only on screen. Every CSS-animated glow is started where the clock already is (a negative animation-delay from performance.now()), so parts mounted at different moments stay in step. Nothing interpolated into the small static <style> each part renders; colours arrive as CSS variables. Respect prefers-reduced-motion (still sky, no chases). No dependencies beyond React.
