# Glass Focus Field: AI prompt

````text
Create a React + Tailwind client component, GlassField: a liquid-glass text field that reacts before, during and after typing. Before focus its rim notices the pointer; focus thickens the glass outward from the point you clicked instead of drawing a ring; each keystroke sends a ripple through the glass from the caret; an error clouds the glass once instead of shaking.

Props: label (required), name, id, type ("text" | "email" | "password" | "search" | "tel" | "url"), value / defaultValue / onChange(value: string), placeholder (visible only once the label has floated), multiline + rows (textarea), hint, error (a message marks the field invalid), required, disabled, autoComplete, tone ("dark" | "light"), tint ("#rrggbb", regex-validated, at 14%), refraction (0–2), className. The id defaults to one from useId.

Structure: a relative, isolated shell (full pill for single-line; 24px radius when multiline) that records the pointer position on pointerdown, in layout pixels (rect-to-offsetWidth ratio, so it works inside a transform-scaled container). Inside it, as SIBLINGS, never nested, so each blurs the page and not another pane:
1. The rest pane: fill rgba(18,18,24,0.22) dark / rgba(255,255,255,0.3) light (or the tint at 8%), backdrop-filter blur(6px) saturate(150%) brightness(1.04).
2. The deep pane: fill rgba(18,18,24,0.26) / rgba(255,255,255,0.5) (or the tint at 14%), backdrop-filter blur(18px) saturate(200%) brightness(1.1) (1.05 light), starting at clip-path circle(0px). On focus, centre the circle on the recorded pointer point (keyboard focus: x 22px at mid-height, 30px down when multiline), commit it with transition none and a forced layout read, then transition clip-path over 440ms cubic-bezier(0.22,1,0.36,1) to a radius reaching the farthest corner. On blur, shrink it to 0 at the same point over 340ms ease-in. No transition under prefers-reduced-motion.
3. A cloud pane for errors: hidden (visibility hidden, opacity 0), backdrop-filter blur(26px) saturate(125%) brightness(1.14) (1.06 light), a milky radial fill (white 0.16 → 0.06 dark, 0.34 → 0.16 light) over rgba(255,69,58,0.12).
4. A bezel band: box-shadow inset 0 0 0 (1 + 1.5b)px white (0.04 + 0.12b) and inset 0 0 (6 + 12b)px white (0.02 + 0.1b), where b is the thickness from the loop.
5. A ripple layer (background-image set by the loop), then a soft face specular (radial 220px at --gf-lx/--gf-ly, white 0.1 dark screen-blended / 0.28 light, opacity 0.8 × --gf-lo).
6. The rim: at rest inset 0 1px 0 white 0.45 (0.8 light), inset 0 −1px 0 white 0.14, 0 8px 28px black 0.16; while focused inset top 0.9, inset bottom 0.32, an inset 1.5px ring at white 0.55 (0.85 light) as the visible focus indicator, and 0 12px 40px black 0.28; box-shadow transition 240ms.
7. The rim light: a 1.5px ring (mask-composite exclude) filled with radial-gradient(150px circle at var(--gf-lx) var(--gf-ly), white 0.95 → transparent 70%), opacity var(--gf-lo).
8. A floating label (15px, 600, pointer-events none), floated to translateY(−10px) scale(0.76) on focus or value, over 240ms; a required field shows an aria-hidden asterisk.
9. The input or textarea: transparent, 16px/24px text, 20px side padding, 22px top and 8px bottom on a 58px single line (28 and 12 when multiline), no outline, placeholder transparent until focus, autofill paint neutralised.
10. An aria-hidden, visibility-hidden mirror div at the same position with the same padding and type (white-space pre, or pre-wrap + break-word at full width when multiline).

The reaction loop (one effect, plain functions, one requestAnimationFrame loop that sleeps when nothing moves and while an IntersectionObserver says the field is off screen; skipped when disabled):
- Proximity: document pointermove/pointerdown store the pointer; each frame convert it to layout pixels with the shell's rect and offsetWidth, take the signed distance to the rounded box, q = 1 − smoothstep(distance / 140). Unfocused, the light targets the pointer clamped to the box with opacity q, and the bezel thickness b targets q. Ease the position over 180ms, the opacity over 220ms, b over 260ms; a light that is out jumps to its target. A finger lifting (pointerup/cancel with pointerType touch) or the pointer leaving the window (pointerout with no relatedTarget) clears the pointer; any scroll (capture, passive) re-measures.
- The rest pane thickens with b: blur(6 + 4b px) saturate(150 + 30b %). In Chromium, while b > 0, prepend url(#rest) to its backdrop-filter, a second displacement filter sharing the deep pane's map at scale round(0.55 × b × full scale). Write -webkit-backdrop-filter (never with url) BEFORE backdrop-filter, so the url version wins where an engine aliases them.
- Caret: measure it in layout pixels by filling the mirror with the value up to selectionStart (bullets for passwords; fall back to the end for email inputs, in a try/catch), appending a zero-width span, reading its offsetLeft (minus the field's scrollLeft) and offsetTop + 12 (minus scrollTop), then emptying the mirror at once so a long value never widens the page. Re-measure on input, compositionend, keyup, select, pointerup, the field's scroll and focus.
- Focused: the light rides with the caret at opacity 0.7 and b = 1.
- Ripples: a native input listener (not React's onBeforeInput) queues one per change, skipping composition updates (one on compositionend instead): inputType starting with "delete" ripples inward, insertFromPaste/Drop is a bigger ripple. Each ripple is a radial-gradient ring at the caret with a crest of white (0.2 dark, 0.5 light) and a faint dark trough (0.1 / 0.06) 9px wide: outward the radius grows 4 → 134px (194 for paste) over 760ms (900) with ease-out cubic, amplitude (1 − a)^1.5 with an 8% fade-in, crest leading; inward it shrinks from 114px to 4 over 640ms with a cosine ease and a sin(πa) envelope, crest leading inward. At most 4 at once, drawn behind the text. None under reduced motion.

Error: tint both panes with rgb(255,69,58) and set aria-invalid; aria-describedby points at the error, otherwise at the hint; below the field an aria-live polite region shows the error (13px, 600, with an inline icon) or the hint (13px, 60% opacity). When error arrives or changes (compare with the previous value kept in a ref, so a mount with an error does not animate), make the cloud pane visible and animate its opacity 0 → 1 (30%) → hold (42%) → 0 over 900ms with the Web Animations API, then hide it with a 920ms timer (not the finish event). Skip under reduced motion. disabled dims the whole field to 50% and switches the reactions off.

Refraction (Chromium only, detected with navigator.userAgentData brands containing "Chromium", never with @supports): an SVG filter (feImage + feDisplacementMap, R = x, G = y, sRGB) whose canvas map is sized to the shell (rounded-rect signed distance, offset along the inward normal by (1 − t/bezel)², encoded 128 + 127·d), regenerated on resize. bezel = min(14 × max(1, refraction), 0.3 × height); scale = round(0.8 × bezel × min(1, refraction)), so refraction up to 1 strengthens the bend and above 1 widens the bent band while the peak offset never passes 0.4 of the bezel. Prepend url(#id) to the deep pane's backdrop-filter.

Output one self-contained "use client" TSX file with no dependencies beyond React. Keep React state to focus and filled; everything that moves is written imperatively from the loop. Build strings with + rather than template literals.
````
