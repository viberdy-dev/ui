````text
Create a React + Tailwind client component, GlassMorphPopover: a liquid-glass popover that grows out of its trigger as a droplet and settles into a flat panel.

Props: label, icon?, children (panel content), title? (the dialog's accessible name, defaults to label), open / defaultOpen / onOpenChange, placement ("bottom" | "top"), align ("start" | "center" | "end"), width (px, default 320), tone ("dark" | "light"), tint ("#rrggbb", regex-validated, at 12%), refraction (0–2), className.

Structure: a relative inline-block wrapper holding (1) the trigger, a 44px glass pill button (backdrop-filter blur(18px) saturate(180%) brightness(1.08), fill rgba(18,18,24,0.36) on dark or rgba(255,255,255,0.55) on light, inset 0 1px 0 white 0.55 (0.9 light), inset 0 −1px 0 white 0.18, 0 12px 40px black 0.28 (0.14 light)) with aria-haspopup="dialog", aria-expanded and aria-controls, the kit press squash (scale 0.98 × 0.97) and spring release cubic-bezier(0.34,1.4,0.64,1); (2) a "neck", an aria-hidden 18 × 20px glass bead centred under (or above) the trigger that bridges the 12px gap; (3) the panel, role="dialog" with tabIndex −1, positioned absolutely 12px below (or above) the trigger, aligned by left/right in px (never a transform, which the animation owns), 28px radius (the kit's panel token), the same glass, a 1px graduated rim (a padding + mask-composite ring with a 160° gradient white 0.6 → 0.12 → 0.06 → 0.22), content padding 16px.

Keep the panel mounted while it closes: track the previous open value during render and set a `closing` flag when it flips to false; the panel is hidden only when neither open nor closing.

The morph runs in a useLayoutEffect (so the panel never paints one full-size frame first). Measure the panel (offsetWidth/Height) and the trigger's centre in the panel's layout pixels. Define three clip-path shapes: (a) a capsule the trigger's width and 0.9× its height, hanging from the panel's near edge at the trigger's centre; (b) a narrower pill (max(56, 0.72 × trigger width)) reaching 58% of the panel's height; (c) inset(0 round 28px). Open: Web Animations on clip-path a → b (offset 0.42, easing cubic-bezier(0.3,0,0.2,1)) → c (spring easing cubic-bezier(0.34,1.4,0.64,1)), 320ms, fill "backwards" only, so the clip lets go when settled and the shadow is not clipped; the neck scales (0.2, 0) → (1, 1) at 35% → (0.3, 0) over 300ms; the content fades and rises 6px after a 140ms delay over 200ms. Close: content fades in 90ms; clip c → b → a over 240ms ease-in with fill "forwards", then clear `closing` from a 250ms timer (not the animation's finish event, which only fires on a rendered frame and can stall in a throttled tab). Only a real closed-to-open change plays the morph: track "settled open" in a ref that survives effect re-runs (React development mounts twice, and props can change while open). If it mounts open, or under prefers-reduced-motion, just show it. Focus the panel (preventScroll) only on a real closed-to-open change that a person caused, then clear that flag, so a prop change while open never steals focus. Once settled, a light follows the pointer across the panel: ease a position toward the pointer (layout pixels via the rect-to-offsetWidth ratio) with a 180ms time constant and an opacity to 1 (0 on leave) with 220ms in a sleeping requestAnimationFrame loop, written to --gmp-lx/--gmp-ly/--gmp-lo, lighting a rim ring (radial 220px, white 0.95) and a soft specular (radial 320px, white 0.16, screen on dark).

Refraction (Chromium only, detected with navigator.userAgentData brands containing "Chromium", never with @supports): an SVG filter (feImage + feDisplacementMap, R = x, G = y, sRGB) with a canvas-generated rounded-rect displacement map sized to the panel (bezel clamp(0.08 × shorter side, 14, 24) × max(1, refraction), at most 0.3 × the shorter side: refraction above 1 widens the bent band instead of deepening it, so the peak offset never passes 0.4 of the bezel; inward offset (1 − t/bezel)², encoded 128 + 127·d), prepended to the panel's backdrop-filter. Glass never fades in, so ramp the feDisplacementMap scale from 0 to round(0.8 × bezel × min(1, refraction)) over the 320ms open with requestAnimationFrame, and back to 0 over 200ms on close.

Close on a pointerdown outside the wrapper and on Escape inside the panel (then return focus to the trigger). Document that the panel is positioned inside the trigger's wrapper, so the wrapper must not sit inside an overflow-hidden ancestor, and that animating clip-path on a backdrop-filter element should be checked in Safari.

Output one self-contained "use client" TSX file with no dependencies beyond React. Build strings with + rather than template literals.
````
