````text
Create a React + Tailwind v4 client component, GlassTintFooter: a liquid-glass footer slab that rises over the bottom of the section above it as it scrolls into view, with a liquid top edge that sloshes when you scroll fast, a pointer light, a glass droplet that glides between its links, and a tint borrowed from the section above.

Props: brand, tagline?, columns ({ title, links: { label, href }[] }[]), legal ({ label, href }[]), note?, newsletter (boolean, default true), onSubscribe?(email), tint? ("#rrggbb" fallback, regex-validated), sample (boolean, default true: read the tint from the section above), tone ("dark" | "light"), refraction (0–2), overlap (px, default 56: how far the slab rises over the section), rise (boolean, default true: tie the rise to scroll), meniscus (0–1.5, default 1: how much the edge sloshes; 0 keeps it still), scroll ("page" default: follow window scroll; "frame": follow the nearest ancestor whose overflow-y is auto/scroll/overlay, for fixed-height boxes; fall back to the page if there is none), className. Hrefs are sanitised: strip tabs and newlines, reject backslashes, allow http(s), mailto, tel and relative paths starting / # ? but not //.

Geometry. Constants: PAD = 26 (glass kept above the resting edge so an upward swing is never cut flat), RADIUS = 28, SWING = 12. The <footer> is a Tailwind @container, pointer-events none, position relative, z-index 10, margin-top −(overlap + PAD). Its only in-flow child is the slab (pointer-events auto, relative, isolate, overflow hidden): fill rgba(14,14,20,0.42) dark / rgba(255,255,255,0.5) light; backdrop-filter blur(20px) saturate(180%) brightness(1.08) (1.04 light) with the -webkit- prefix; initial clip-path inset(PAD 0 0 0 round 28px 28px 0 0) so the first paint (and no-JS) shows the risen slab. Inside the slab: a content wrapper (relative, isolate, margin-top PAD) holding the droplet and the content; the edge height y0 (slab-local, PAD when risen, PAD + overlap when not) drives translate3d(0, round(y0 − PAD), 0) on the content wrapper, so copy rides with the edge.

Rise (one requestAnimationFrame loop in an effect). Each frame read the footer's and the scroll root's getBoundingClientRect (root = window with top 0 and bottom innerHeight) and convert to layout pixels with k = footer.offsetHeight / rect.height (works inside transform-scaled previews). shown = (rootBottom − footerTop)·k − PAD − overlap; range = 0.85 · min(slabHeight − PAD − overlap, rootHeight·k); p = smoothstep(shown / range) (1 when rise is off or under prefers-reduced-motion); target y0 = PAD + overlap·(1 − p). Ease y0 to it with a 80ms time constant. This guarantees p = 1 at the bottom of the page and on short pages.

Meniscus. Three standing waves across the flat top between the corners, sin(k·π·u) for k = 1..3, each a damped spring (1.3 Hz ζ 0.40, 2.0 Hz ζ 0.36, 2.8 Hz ζ 0.36, semi-implicit Euler, dt capped at 1/30). Scroll speed v = d(footerTop − rootTop)·k/dt, low-passed with 70ms. Mode 1 target = SWING·meniscus·tanh(−v/1400) (moving up, the middle sags; moving down, it bulges); mode 2 target = 0.5·bias·t1 where bias is the pointer's side of the slab (−1..1, default 0.35); mode 3 = 0.2·t1. Released, the springs overshoot and settle within about a second. Soft-clamp each sample with (PAD − 2)·tanh(d/(PAD − 2)). Sample 24 segments and join with quadratic curves through the midpoints; when every mode is below 0.05px draw a straight line. Build clip = M0 H L0 y0+r A r r 0 0 1 r y0 [wave] A r r 0 0 1 W y0+r L W H Z and set it as clip-path: path("...") (and -webkit-clip-path) on the slab; never use backdrop-filter url() for the edge. The loop sleeps when nothing moves (no scroll this frame, |v| < 2, y0 settled, springs below 0.12px and 1.5px/s), snaps to rest when it sleeps, and runs only while an IntersectionObserver (root = the scroll root, rootMargin 64px) sees the footer. A ResizeObserver on the slab stores width and height and places the edge at once on first measure. Scroll listeners are passive; do nothing on scroll when reduced motion is on or both rise and meniscus are off.

Drawn edge. An aria-hidden SVG (absolute, full size of the footer, overflow visible, pointer-events none) after the slab: a path in defs holding the rim (the clip's top plus both sides at x = 0.5 and W − 0.5 down to H, fill none), a clipPath with the clip path (inside) and one with a large rect plus the clip path, clip-rule evenodd (outside). Draw with <use href>: a shadow above the edge (black strokes 56/28/10px at 0.035/0.05/0.06 dark, half on light, clipped outside), a lit lip just inside it (white strokes 16/8/3px at 0.045/0.06/0.1 dark, 0.08/0.1/0.16 light, clipped inside), the rim at 1.2px stroked with a userSpaceOnUse vertical gradient from y0 − 4 to H (white 0.6 dark or 0.95 light at 0, 0.12 at 0.38, 0.06 at 0.7, 0.22 at 1), and the pointer-lit rim at 1.6px stroked with a userSpaceOnUse radial gradient (r 280, white 0.95 to 0 at 0.7) whose cx/cy follow the light and whose opacity is the light's. Before the edge goes live, a CSS 1px rim ring (top PAD, radius 28 28 0 0, mask-composite exclude) stands in; hide it on the first paint.

Pointer light. On the slab: pointermove/pointerdown in layout pixels ease a position (180ms) and an opacity (220ms, 0 on pointerleave) in a loop that sleeps when settled; a light that is out starts at its new target instead of streaking. Write --gtf-lx/ly/lo for a soft specular layer (radial-gradient 420px, white 0.14 dark screen-blended / 0.3 light, 65%) and update the SVG lit rim. Keyboard parity: focusing any link, input or button in the footer aims the light at its centre; focus leaving the footer lets it fade.

Droplet. A span inside the content wrapper at z-index −1 (under the link text, which is never bent), rounded-full, drawn as a clear lens: radial tint of rgba(var(--gtf-rgb), 0.26) over linear white 0.2 → 0.04 → 0.1 (light: 0.7 → 0.3 → 0.45), shadow inset 0 1px 0 white 0.85, inset 0 −1px 1px white 0.3, inset 0 0 10px white 0.16, 0 6px 18px black 0.2. Links carry data-gtf-link, are inline-block with outline none inline (focus shows as an underline, offset 4) and a transform transition (300ms cubic-bezier(0.34,1.4,0.64,1), none under reduced motion). On pointerover or focus of a link, target its box measured with offsetLeft/offsetTop summed up the offsetParent chain to the wrapper, padded 9px across and 4px down; spring x, y, width, height (k 120, c 15, about half a second with a small overshoot); scale it by 1 + |v|/3200 along each axis (max 0.22, the other axis narrowing by half); presence eases over 140ms and scales it from 0.25, and a droplet that is not yet there forms at its target instead of flying in. The link under it scales to 1.05. On leaving a link for a non-link, or focus leaving the links, release after 140ms (so crossing a gap keeps it). Follow reflow with a ResizeObserver. Under reduced motion it moves without gliding or stretching.

Tint sampling (effect): read the footer's IMMEDIATE previousElementSibling: its data-glass-tint if a valid #rrggbb, else its computed background-color if at least 20% opaque, else the tint prop, else rgb(124,92,255); write "r,g,b" to --gtf-rgb on the footer. Watch that element (MutationObserver on data-glass-tint, style, class) and the parent's childList. In development, console.warn once when there is nothing to sample. The tint layer fills the slab, is translated down to y0, background-color rgba(var(--gtf-rgb), 0.34) (0.26 light) masked from black at the top to 45% at 38% and 12% at the bottom, transitioning background-color over 600ms.

Refraction (Chromium only, detected with navigator.userAgentData brands containing "Chromium", never with @supports): an SVG filter (feImage + feDisplacementMap, R = x, G = y, sRGB) whose map is generated at half resolution on a canvas, height slabHeight + overlap + 2, for a rounded box whose top sits PAD pixels down (neutral above) and runs far below; bezel min(44 × max(1, refraction), 0.3 × (slabHeight − PAD)); offset (1 − t/bezel)² along the inward normal, encoded 128 + 127·d. The loop sets the feImage y to round(y0 − PAD) so the bent band follows the edge, and the scale to round(0.8 × bezel × min(1, refraction) × rise progress), so the glass appears by its refraction ramping from zero. Prepend url(#id) to the slab's backdrop-filter.

Content in a max-width 1180px block (24px side padding, 48px at @3xl; 56px top, 64px at @3xl, 32px bottom): a two-column grid at @3xl (1.3fr brand, 2fr links). Brand block: the name (22px, 600, −0.02em), the tagline (15px, 66% opacity), and, when newsletter is on, a form: a label ("One email a month", then "You're subscribed." after submit) and a glass capsule (white 0.08 fill, inset rims) with an email input (required, autocomplete email) and a solid Subscribe pill; submit prevents default, calls onSubscribe and sets the subscribed state; it posts nowhere by itself. Links: a nav labelled "Footer" with 2 columns, 3 at @xl, each a 13px 600 title at 66% opacity and 15px links. Bottom row after a 1px divider: the note and the legal links (also droplet links), stacked, side by side at @2xl.

Output one self-contained "use client" TSX file with no dependencies beyond React; export the FooterLink and FooterColumn types. Put each loop in one effect as plain functions (share controls through one ref), measure in layout pixels, and build strings with + rather than template literals.
````
