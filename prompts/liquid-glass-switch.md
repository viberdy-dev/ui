Create a React + Tailwind client component, LiquidGlassSwitch: an iOS-26-style toggle whose knob turns into a clear glass lens while it is held or dragged, magnifying the track beneath it.

Props: checked + onCheckedChange (controlled) or defaultChecked (uncontrolled), label (visible, clickable, and the accessible name via aria-labelledby with a sanitised useId), tint ("#rrggbb" for the on colour, validated with a regex, default #34c759), size ("md": track 64x28, knob 38x24, inset 2 | "lg": 80x36, knob 48x30, inset 3), disabled, labelSide ("end" default, "start" puts the label first for settings rows), className.

Structure: a <button role="switch" aria-checked> with touch-action none and a visible focus ring. The track is two layers: an off layer rgba(120,120,128,0.36) and an on layer in the tint, clipped with clip-path: fully open when on, inset(0 100% 0 0 round 999px) when off, and inset(0 Rpx 0 0 round 999px) while dragging so the fill runs to the knob's centre. The knob is an absolutely positioned pill with overflow hidden and a shadow 0 2px 7px black at 0.28. Inside it: (1) a second copy of the track, positioned at (−x, −topInset) so it lines up exactly with the real track; (2) a glass layer with a vertical white gradient (0.3 → 0.04 → 0.1) and inset rims (top white 0.85, bottom 0.3, 6px inner glow 0.3); (3) a solid white layer on top that fades out over 200ms while held.

The lens: the knob's transform is translateX(x) scale(var(--lgs-scale)). The button sets --lgs-scale to 1, and to 1.32 when data-held="true" (not under prefers-reduced-motion). Because the aligned track copy scales with the knob around its centre, the track reads as magnified through clear glass. Wrap the copy in a knob-sized span with CSS filter: url(#lens), an SVG filter whose feImage is a displacement map generated on a canvas for the knob size (rounded-rect signed distance, radius kh/2, bezel min(0.34·kh, 9px), inward offset (1 − t/bezel)², red = 128 + 127·dx, green = 128 + 127·dy) feeding an feDisplacementMap at scale 12 with color-interpolation-filters sRGB, so the fill edge curves at the knob rim. Apply that filter from an effect in Chromium only (navigator.userAgentData brands contains "Chromium"): an image-driven displacement filter on HTML content is only verified there, so Safari and Firefox keep the magnified copy with a straight edge.

Behaviour: pointerdown (primary button only) captures the pointer and sets data-held; pointermove drags the knob between the insets (converting screen pixels to layout pixels with offsetWidth / rect width, so it tracks inside a scaled container) and moves the knob, its track copy and both fill clips with no transition; pointerup after a drag of more than 3px commits by position (past the middle = on) and animates everything home with 460ms cubic-bezier(0.34, 1.4, 0.64, 1); pointercancel returns to the committed position. A tap, a label click, or Space/Enter toggles and flashes the glass state for 280ms. The click that follows a drag is ignored. Write the knob, copy and clip positions straight to the DOM through refs in a module-level placeKnob() helper; an effect re-places the knob whenever the value changes. Clear the flash timer on unmount.

Output one self-contained "use client" TSX file with no dependencies beyond React. Build strings with + rather than template literals.
