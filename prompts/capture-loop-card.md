# Capture Loop Card: AI prompt

Paste this into Cursor, Claude Code, v0, Lovable or Bolt to generate **Capture Loop Card** from scratch, or edit it first to restyle it. The finished code is [components/capture-loop-card.tsx](../components/capture-loop-card.tsx); the live demo is on [viberdy.dev](https://viberdy.dev/library/capture-loop-card?ref=github).

````text
Create a React + Tailwind v4 client component, CaptureLoopCard: a dark bento tile whose picture is a tightly cropped, muted loop of the product (a few seconds of a real screen), which plays only when someone shows interest.

Props: label? (mono), title, body?, href? (the whole tile becomes a link through a stretched ::after on the title link; the play control stays above it as its own button), sources? ({ src, type? }[], most efficient first), poster?, focus (video only; CSS object-position, default "50% 50%"), zoom (video only; 1–2, clamped: scale the video from the focus point for a tighter crop), alt? (describes the loop; without it the picture is aria-hidden), loopMs (default 6000, for code-drawn captures), size ("md" | "lg"; lg is for a 2x2 hero: 24px title, 15px body), children (a code-drawn capture used when there are no sources), className. Links are sanitised (strip tabs and newlines, reject backslashes, allow http(s), mailto, tel and relative paths starting / # ? but not //); media URLs allow http(s) and relative paths (no other scheme before the first / ? or #, not //, no backslashes).

Kit tokens: tile #0f1012 with an inset 1px hairline at white 0.08, radius 20, filling its grid cell (h-full, flex column); the picture sits 6px inside (radius 14, concentric) on #131417 with its own 0.06 inset hairline; mono label 11px uppercase +0.12em at white 50% in var(--font-mono, var(--font-geist-mono, ui-monospace, …)); title 17px/600 (md), body 13px at 55% white; no shadows, no lift. The pointer light: on pointermove, coalesced to one write per animation frame, set --clc-x/--clc-y in layout pixels (rect scaled by offsetWidth / rect width) and --clc-o 1 (0 on leave); a hairline ring lit by radial-gradient(180px circle, white 0.7 → transparent 70%) (padding 1px, mask-composite exclude) and a glow (radial 260px, white 0.07), both at opacity var(--clc-o) with 200ms transitions, pointer-events none.

Playing is derived, never stored: playing = pinned || (hovered by a mouse && not held && motion allowed). Mouse pointerenter sets hovered and clears held; pointerleave clears hovered and held (and cancels a pending light frame). The control (a 32px button 6px inside the picture's corner, so 12px from the tile's edge, radius 8, concentric with the picture's 14, #0f1012 with a 0.12 hairline, play and pause glyphs drawn in SVG; its aria-label says what it will do, "Play loop" or "Pause loop", with no aria-pressed alongside a changing label) toggles: if playing, unpin and hold (so hover does not restart it until the pointer leaves); otherwise pin. When the tile is not a link, a click on the picture toggles too. Read prefers-reduced-motion with useSyncExternalStore; under it, hover never plays, but the control still does. An IntersectionObserver clears pinned, hovered and held when the tile leaves the screen (a wheel scroll under a still pointer fires no pointerleave).

Video: muted, loop, playsInline, preload="metadata", poster, object-fit cover at the focus point; play() when playing (catch the promise and unpin on failure, but only if that effect run is still current), pause() otherwise. A hairline under the picture (1px at white 10%, filled at white 70% from the left) tracks progress: for video, scaleX(currentTime / duration) on requestAnimationFrame while playing; for code-drawn captures, one infinite linear Web Animation of scaleX 0 → 1 over loopMs that is paused and played with the tile. The picture sets the custom property --clc-play to "running" or "paused" (and data-playing), so a code-drawn capture's CSS animations use animation-play-state: var(--clc-play).

Output one self-contained "use client" TSX file with no dependencies beyond React. Build strings with + rather than template literals.
````
