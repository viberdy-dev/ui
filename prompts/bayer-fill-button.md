# Bayer Fill Button: AI prompt

Paste this into Cursor, Claude Code, v0, Lovable or Bolt to generate **Bayer Fill Button** from scratch, or edit it first to restyle it. The finished code is [components/bayer-fill-button.tsx](../components/bayer-fill-button.tsx); the live demo is on [viberdy.dev](https://viberdy.dev/library/bayer-fill-button?ref=github).

````text
Build a React + Tailwind button, `BayerFillButton({ children, href, onClick, type, variant, size, lit, disabled, ariaLabel, ariaPressed, className })`.

Build 65 mask tiles once: an 8x8 SVG (shape-rendering crispEdges) with the cells whose Bayer index is below the level filled, as data URIs. The face: a 1px border in the ink, the label in paper on the ground. Over it, an absolutely positioned fill in the ink holding a second copy of the label in the ground colour (aria-hidden), masked by the tile for the current level at 2 CSS px a cell, snapped to whole device pixels. A small requestAnimationFrame loop walks the level toward 64 when hovered, focused, pressed or lit (64 levels in 260ms) and back to rest (5 cells, or 0 for the ghost) in 360ms, writing mask-image straight to the element (React renders the first mask only). Pressed: the tile halves (1px cells) and the face translates 1px. Inks: paper (the default, for primary actions), signal (#ff4f2b, for a momentary action), ghost (a 16% hairline).

Dither & ASCII grammar: a warm black ground #0b0b0d (panels #121214, raised #19191c), one ink, paper #f3f0e6 (text at 92/60/38%, hairlines at 8% and 16%), and one signal colour, vermillion #ff4f2b, used as a second ink inside the pictures (the sun, a glint, a ball, a newly lit dot, a wordmark) and for a live state confined to a small mark (a square that lights, a peak character), never as a panel fill; a primary control's ink is paper, with signal kept for a momentary action. Every picture is computed and printed on purpose: rendered scenes dither in linear light and photographs on a gentler 1.5 curve so their midtones stay full, cells snap to whole device pixels (never blurred into grey), the 8x8 Bayer matrix for anything CSS, 64x64 void-and-cluster blue noise for the signature pictures, true error diffusion only on the CPU. Type stays crisp and undithered: Funnel Display through var(--font-funnel, "Funnel Display", ...) at 600-700 with -0.035em tracking for display, Geist for reading, Geist Mono uppercase with +0.14em tracking for labels and for every glyph an ASCII transform draws. Radii 10px controls, 14px cards, 18px panels. Motion: a transform change dissolves through blue noise in ~450ms, a fill prints in Bayer order in ~260ms and out in ~360ms, pictures print in on first view over ~900ms, ambient scenes loop over 30s or more. Respect prefers-reduced-motion (the picture still, changes instant). No dependencies beyond React.
````
