# Chrome Rim Input: AI prompt

Paste this into Cursor, Claude Code, v0, Lovable or Bolt to generate **Chrome Rim Input** from scratch, or edit it first to restyle it. The finished code is [components/chrome-rim-input.tsx](../components/chrome-rim-input.tsx); the live demo is on [viberdy.dev](https://viberdy.dev/library/chrome-rim-input?ref=github).

````text
Build a React + Tailwind form, `ChromeRimInput({ label, placeholder, action, onSubmit, done, failed, finish })`: an email field in a pill with a chrome rim.

A visible mono label, then a 60px pill (graphite, inset shadow) with an SVG sized to it: a rounded rect stroked with a linearGradient of the chrome ramp whose gradientTransform rotates toward the pointer (window pointermove, once per frame); two more rects with pathLength 1000 and a 40/960 dash used as ripples; while sending, a rect with a 120/880 dash lapping via a CSS keyframe. Inside: the input (type email, required, autocomplete email) and a ChromePillButton submit.

On each change, measure the caret's x with canvas measureText in the input's font (email inputs have no selection range; use the end of the value), convert it to a position along the rim (rects start on the top edge at x = rx and run clockwise), and animate the two ripple rects' stroke-dashoffset 320 units each way over 720ms, fading. Submit: checkValidity or show a hint; set sending, await onSubmit (required); on success set done: the pill's width transitions to 60px, its background becomes chrome with the horizon low, a check pops in, and the confirmation appears beside it; on failure the rim goes matte and the failure message shows. One polite live region announces every outcome.

Liquid Chrome grammar: a graphite room (ground #0c0d10, panels #141519 and #1b1c21, hairlines white 7% and 16% drawn as inset box-shadows or SVG strokes, never border colours), ink #f4f5f7 at 94/62/40%. Chrome is a reflected room, never a flat grey gradient: four bands (#08090b, #4b4f58, #c9ced6, #ffffff) arranged as a bright sky over a hard dark horizon over a lit floor, multiplied by a finish (chrome #ffffff, gold #f2cf92, rose #f1bcb4, cobalt #b9cbff, or any #rrggbb validated against /^#[0-9a-fA-F]{6}$/) and handed to CSS as --lc-0 to --lc-3 with the horizon position in --lc-h. Colour appears only as a thin film on Newton's series (silver #d8dce2, champagne #eadfc4, magenta #d68fc7, cyan #8fd6d1, green #a8d68f, gold #d6b98f, violet #b48fd6, unevenly spaced), never a hue-rotate rainbow. Chrome goes only on heavy, curved forms (display type, pills, discs), never on hairlines. Display type is Archivo at 800 with font-stretch 125% and -0.02em tracking through var(--font-display, "Archivo", ...); UI in Geist; captions in Geist Mono, uppercase. Pills and 26px radii. The room eases toward the pointer in about 220ms, ambient drift runs 40s or slower, presses squash about 4% in 130ms. Keyframes and a focus ring (a .lc-scope rule with border-radius: revert-layer) live in a small static <style> the component renders itself; nothing is interpolated into it. Respect prefers-reduced-motion. No dependencies beyond React.
````
