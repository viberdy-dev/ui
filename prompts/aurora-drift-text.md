# Aurora Drift Text: AI prompt

Paste this into Cursor, Claude Code, v0, Lovable or Bolt to generate **Aurora Drift Text** from scratch, or edit it first to restyle it. The finished code is [components/aurora-drift-text.tsx](../components/aurora-drift-text.tsx); the live demo is on [viberdy.dev](https://viberdy.dev/library/aurora-drift-text?ref=github).

````text
Build a React + Tailwind heading, `AuroraDriftText({ text, as, palette, align, className, style })`.

Register --au-d1, --au-d2 and --au-d3 as inherited <percentage> properties and drift them on 32s, 38s and 45s ease-in-out loops. Fill the words with background-clip: text over five layers: repeating 1px ray threads every 6px (sliding 120px over 32s), a radial of the core (lightened 35% toward white) at calc(var(--au-d1) * (1 - var(--au-pull)) + var(--au-x) * var(--au-pull)), a radial of core2 at --au-d2, a radial of the blend at --au-d3, and a base of white at 30-50%. Behind the words an aria-hidden copy with the same fill, blurred 18px at 0.45. On document pointermove, when the heading is on screen, set the target x from the pointer and a pull that falls to zero 180px above or below the text; ease both each frame (1 - e^(-4dt) and 1 - e^(-3dt)) and write --au-x and --au-pull. Bricolage Grotesque 650, clamp(44px, 8cqw, 124px), leading 1, text-wrap balance.

Aurora grammar: a near-black night #050608 (panels #0a0d12, raised #0f141a; ink #ecf4f8 at 94/64/42%; hairlines at 8% and 16%). The light is real aurora, coloured by altitude: a core in mint #7cf5c4 drifting toward sky #38bdf8 on one shared 60s clock, a violet #a78bfa blend above it, a rose #f472b6 crown seen only in a strong display, and an indigo #5b6cc4 fringe under the lower border (palettes: boreal, verdant #6ee7a0, violet). Never a hue-rotate cycle, never full-saturation rainbow; colour is a function of position and altitude, blended through noise. Curtains have a bright lower border, rays that rise and fray, folds that brighten where a sheet turns edge-on, and stretches that are lit and gone; layers are phase-offset, never in unison. A static 2% dither against banding (not re-seeded). Text never sits on bare aurora: frosted glass (blur 14-18px) or the dark between curtains. Bricolage Grotesque through var(--font-bricolage, "Bricolage Grotesque", ...) at 600-650 for lit display type only, Geist for UI, Geist Mono uppercase captions. Radii 20-24px on panels, pills for controls. Motion: the 60s aurora clock, ambient drifts of 30s and longer, discrete hover or focus changes under 450ms, pointer chases that settle over 600-900ms (1 - e^(-4dt)); WebGL runs at 30fps and only on screen. Every CSS-animated glow is started where the clock already is (a negative animation-delay from performance.now()), so parts mounted at different moments stay in step. Nothing interpolated into the small static <style> each part renders; colours arrive as CSS variables. Respect prefers-reduced-motion (still sky, no chases). No dependencies beyond React.
````
