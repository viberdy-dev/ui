Create a React + Tailwind v4 footer, WarningTapeFooter: a neo-brutalist footer under a strip of hazard tape you can grab and throw, whose sign-up stamps the tape, and whose giant wordmark is a row of keys that press onto their own ink plates.

Props (export WarningTapeFooterProps, TapeColumn { title, links } and TapeLink { label, href }): brand (default "hod"), home (the brand link, default "/"), tagline, tape (phrases), speed (seconds per loop, clamped to 30 or more, default 48), tilt (-4 to 4 degrees, default -2), columns (default three), social, status (a short line in the bottom bar; empty hides it), onSubscribe(email) that may return a promise (omit to hide the sign-up), subscribeLabel, stamp (default "You're in"; empty turns it off), wordmark (default true), keys (default true: typing a letter of the brand presses it), year (no default: pass it from the server, never call new Date() in render), accent (yellow #ffd23f default, coral #ff6b6b, blue #74b9ff, lime #b4f462, pink #ff5fa2 or a regex-validated hex; own-key lookup), ink (#000), ground (cream #fffdf5 or white), className. Sanitise every href: strip tabs and newlines, refuse backslashes, allow http(s), mailto, tel and paths starting / # ? but not //.

Kit grammar: 3px ink borders and rules set inline, square corners, hard ink shadows with no blur (a shadow never interpolates), 100ms linear presses, stamps in hard steps(), one accent per page, type in var(--font-display, "Archivo", "Archivo Black", "Arial Black", …) at 800-900, var(--font-sans, …) and var(--font-mono, …) for labels. Put --wtf-ink, --wtf-fill (the accent) and --wtf-ground on the footer and keep every other state rule in one static <style> string (no user values inside it).

The tape: a 60px band in the accent with 3px ink rules top and bottom and a 5px hard shadow, inside a wrapper 4% wider than the footer on each side and rotated by tilt. It holds a track (w-max) of two identical runs; each run (relative) repeats the phrases (heavy 22px caps, 28px padding) each followed by an 84px block of 45-degree hazard stripes (repeating-linear-gradient 135deg, ink 0-12px, accent 12-24px, 3px ink sides). The band is focusable: role="marquee", tabIndex 0, aria-label of the phrases, aria-describedby a visually hidden hint ("Drag the tape, or use the arrow keys, to move it. It stops while it has focus."); the runs are aria-hidden. Cursor grab; while grabbed (data-grab) cursor grabbing and it lifts: translate(-2px,-2px) with the shadow at 7px, a 0ms cut. touch-action pan-y.

Physics, in one mount effect with the state in a ref (offset x in px, velocity v, run width w measured from the first run by a ResizeObserver, flags for drag, hover and keyboard focus) and draw/kick functions stored on the ref: each frame (dt clamped to 50ms) v moves toward a target with time constant 0.45s, v += (target - v) * (1 - exp(-dt / 0.45)), then x += v * dt, wrapped into (-w, 0], written as translate3d on the track. The target is -w / seconds (the crawl) or 0 while dragged, hovered by a mouse, focused from the keyboard (onFocus checks :focus-visible, so the focus a click leaves behind does not stop it) or under reduced motion. That one rule gives the throw its momentum, its friction and the ease back into the crawl. Stop requesting frames when the target is 0 and |v| < 1 (idle) or when an IntersectionObserver says the tape is off screen; kick restarts it. Drag: on pointerdown capture the pointer and record the pointer's position along the tape's tilted axis ((clientX cos a + clientY sin a) times the footer's layout-to-screen ratio); on move set x = x0 + delta and draw directly; keep the last 100ms of samples (e.timeStamp); on release set v from them (clamped to ±4000 px/s, 0 under reduced motion), clear the hover pause so the throw glides and rejoins the crawl even under the pointer, and kick. ArrowLeft/ArrowRight add ±700 px/s (×2.5 with Shift, clamped to ±3000) or jump 64px under reduced motion.

The stamp: after onSubscribe resolves, compute where the form's centre sits on the tape, convert to one run's coordinates ((onTape - x) mod w, kept 130px from the run's ends) and render the stamp in both runs at that left: absolute, centred with translate(-50%,-50%) rotate(-4deg), 38px tall, 3px ink border, the ground colour, a 5px ink shadow, 900-weight 20px caps. It arrives as a hard two-frame cut: keyframes from scale 1.3 with no shadow to its resting state, 120ms steps(1,end), only when motion is allowed. It then crawls away with the tape and comes back every loop.

Below the tape, inside max-width 1200px: a grid (from @4xl: 1.25fr and 2fr) between 3px rules: the brand (an accent square with a 3px border beside the name at 900, 34px), the tagline, and the sign-up: a real form with method post, a labelled email input (useId, required, maxLength 254, autocomplete email, fills with the accent on focus) joined to an ink submit button with a 5px shadow that lands on it when pressed; on submit prevent the default, call onSubscribe with the trimmed email, show "Sending…", then "Done" and "You're on the list." in a role="status" line and stamp the tape, or "Didn't send. Try again."; the input becomes read-only while sending and after. Then a nav labelled Footer with the columns (mono 12px caps headings, links at 800, 18px with a 3px underline on hover), split by 3px rules from @2xl. A mono bottom bar holds "© year brand", the status with a square bullet, and the social links.

The wordmark (if wordmark): an aria-hidden paragraph at 900 and 31cqw (the footer is an inline-size container), leading 0.8, tracking -0.06em, font-kerning none, cropped by the footer's overflow-hidden bottom edge (margin-bottom -0.2em). It holds two identical lines of per-letter inline-block spans (spaces as a non-breaking space built with String.fromCharCode(160)): an absolute plates line (inset-x 0, same padding, pointer-events none, translate 8px 8px, letters in ink with a 6px ink -webkit-text-stroke) under a faces line where each letter is a key (data-ch = the lowercase letter) wrapping a face in the ground colour with a 6px ink stroke and paint-order stroke fill (a 3px visible outline). A key with data-down moves its face translate(8px, 8px) onto its plate in 100ms linear and fills it with the accent; the plate never moves, so the shadow never interpolates. Mouse and pen press on pointerenter and release on pointerleave; touch presses on pointerdown and releases 140ms after pointerup. Keyboard: a window keydown listener (only while the wordmark is on screen per an IntersectionObserver, no Ctrl/Meta/Alt, not composing, and neither the target nor document.activeElement a text field) presses every key whose letter matches, and keyup releases them after at least 120ms; blur releases all.

Write the focus-ring declarations as important utilities (focus-visible:![outline-style:dashed], ![outline-width:3px], ![outline-offset:4px], ![border-radius:0]) with the ring colour inline, and borders that only appear at a container width (for example @4xl:![border-left:3px_solid_var(--wtf-ink)]) as important too, so a host's unlayered :focus-visible or border-colour rule cannot repaint them. Output one self-contained "use client" TSX file with no dependencies beyond React. Build strings with + rather than template literals.
