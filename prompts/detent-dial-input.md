Build a React + Tailwind input, `DetentDialInput({ label, min, max, step, value, defaultValue, onChange, format, detents, finish, size, name, hint, className })`.

Use the kit's CSS-3D dial (knurled discs under a glass cap, ticks = detents) as a role=slider element. The dial angle is ((value - min)/step) x (360/detents) degrees, followed by a spring (stiffness 340, damping 26). Dragging: on pointerdown remember the pointer's angle around the dial's centre and the value; on move, unwrap the angle change across the top and set value = start + (change / degrees per detent) x step, rounded to the step and clamped; the copper marker glows for 120ms on each change. Keys: arrows +-step, Page Up/Down +-10 steps, Home/End. The value in Hanken Grotesk 600 at 44px, a hint line, and a hidden input with name.

Spatial 3D grammar: a dark studio, ground #0a0a0d (panels #101114, raised #16171b, ink #f2f1ee at 92/60/38%, hairlines at 8% and 16%), and one accent, anodised copper #ff7a3d, used only as light (a status arc, a detent marker, an active underglow), never as a fill. One object in three finishes, as material parameters: titanium (base #b9bcc2, gloss 0.62, specular 0.8, fully metallic), ceramic (#ece7dd, gloss 0.4, specular 0.25, a little subsurface wrap) and soft-touch polymer (#1b1c20, gloss 0.3, specular 0.12, the rim kept up so it holds against the ground). One rig for everything: a warm key from (0.55, 0.65, 0.42) at 1.15, a cool fill from (-0.4, -0.15, 0.55) at 0.3, a rim from behind at 0.65, soft shadows (k 16), five-tap occlusion and a studio reflection (a big softbox overhead left, a strip behind right), in linear light with a filmic curve and a 1/255 dither. Parts are blended with small smooth-min radii (8-15% of the smaller part) so the object reads as machined, not melted. Hanken Grotesk through var(--font-hanken, "Hanken Grotesk", ...) at 600-800 for display, Geist for reading, Geist Mono uppercase for readouts. Radii 24px panels, 20px cards, 14px controls, the dial full round. Motion: detent springs (stiffness 340, damping 26, ~380ms), orbit inertia that decays in ~270ms, an idle drift of 6 degrees a second on the page clock after 2.5s of stillness, hovers and presses in 90-420ms. Respect prefers-reduced-motion (a still three-quarter view you can still turn by hand; no drift, no scatter). No dependencies beyond React.
